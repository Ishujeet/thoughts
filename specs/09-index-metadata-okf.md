# 09 — Index & metadata (OKF)

Status: Draft

Reference: Open Knowledge Format v0.2 — https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md

## Purpose

Every thought is an OKF **concept**; the brain is an OKF **bundle**. This spec pins which OKF fields we use, what we add, and how the CLI generates `index.md` and `log.md`.

## Bundle

- Brain root `index.md` declares `okf_version: "0.2"` in frontmatter. No other index has frontmatter.
- Reserved filenames `index.md` and `log.md` are generated by `sync`; all other `.md` files under the zones are concepts.
- `references/` under any zone follows the OKF convention for mirrored external material.

## Concept frontmatter

| Field | OKF | Req | Notes |
|-------|-----|-----|-------|
| `type` | required | MUST | One of the built-in types (`Plan`, `Spec`, `Research`, `Decision`, `Pull Request`, `Commit`) or an org-declared type from `brain.yml`. Unknown types are tolerated. |
| `title` | recommended | MUST | Display name. |
| `description` | recommended | SHOULD | One sentence. Empty allowed in drafts; `sync` warns. |
| `resource` | recommended | MAY | URI of the underlying asset (e.g. a PR URL, a code path). |
| `tags` | recommended | MAY | List. |
| `status` | lifecycle | MUST | `draft` / `stable` / `deprecated`. Default `draft` for new thoughts (differs from OKF's default of `stable` — we make it explicit). |
| `stale_after` | lifecycle | MAY | ISO 8601. `status` and `search` surface stale thoughts. |
| `generated` | trust | MUST | `{ by, at }`. `by` follows OKF actor convention: `human:<id>`, `<agent>/<version>`, `process:<id>`. |
| `verified` | trust | MAY | List of `{ by, at }`. Drives trust tier. |
| `sources` | provenance | MAY | List of `{ resource, title?, id? }`. Used by `--links-to`. |
| `repo` | **ours** | MUST | Owning `repo_id`, or `shared`, or `user:<id>`. Redundant with path, kept for portability. |
| `links` | **ours** | MAY | `{ ticket, pr, branch, work_item }`. Integration keys; see [10-integrations.md](10-integrations.md). |
| `supersedes` / `superseded_by` | **ours** | MAY | Bundle-relative paths. For decisions. |

Consumers MUST preserve unknown fields on rewrite (OKF rule). The CLI never strips fields it doesn't know.

## Trust tiers

Derived exactly as OKF:

| Tier | Condition |
|------|-----------|
| unverified | no `verified` |
| machine-confirmed | `verified[]` contains only non-`human:` actors |
| human-reviewed | any `verified[].by` starts with `human:` |

`thoughts verify <path>` appends `{ by: human:<me>, at: now }` and, if `status: draft`, offers to set `stable`.

## Actor ids

- Humans: `human:<user-id>` where `user-id` comes from global config (default: git `user.email` local part).
- Assistants writing via the standard kit SHOULD set `generated.by` to `<tool>/<model>` (e.g. `claude-code/claude-fable-5-1`). The commands pass this via `thoughts new --set author=…`.

## Generated `index.md`

One per bundle root, per zone, and per `repos/<id>`. Format:

```markdown
# payments-api

## Specs
* [Refund endpoint v2](/repos/payments-api/specs/2026-09-08-refund-endpoint-v2.md) - Add v2 refund API with idempotency. `draft`
* …

## Decisions
* …
```

- Sections are kinds in `brain.yml` order; empty kinds are omitted.
- Entries sorted by date descending (from filename prefix), then title.
- Entry = `* [title](abs-path) - description` + `` `status` `` suffix when not `stable`.
- Root `index.md` lists zones and repos, each with a one-line count summary, plus a **Recently updated** section (last 20 concepts across the brain).

## Generated `log.md`

Append-only, newest date first:

```markdown
## 2026-09-08
* **Added**: [Refund endpoint v2](/repos/payments-api/specs/2026-09-08-refund-endpoint-v2.md) by human:ishujeet
* **Updated**: [Idempotency key format](/shared/decisions/2026-09-01-idempotency-key-format.md) — status draft → stable
```

Entries derive from git diff between last sync commit and working tree. `sync` never rewrites past dates.

## Validation rules (`thoughts lint`)

- E: frontmatter missing or unparsable.
- E: `type`, `title`, `status`, `generated`, `repo` missing.
- E: `repo` disagrees with path zone.
- W: `description` empty on a `stable` thought.
- W: link target does not exist in bundle (OKF tolerates; we warn).
- W: `stale_after` in the past and `status` not `deprecated`.

## Open questions

- Should `index.md` include trust tier badges? Adds noise; leave to `status`/`search`.
- Adopt OKF `Attested Computation` for e.g. "which services consume event X" as a runnable query? Interesting later; not v1.
